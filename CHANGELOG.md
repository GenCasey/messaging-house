# Changelog

## 1.0.0 (2026-09-03)

First public release.

- Six-stage chain: customer profile, value map, four why-buys, messaging house, value proposition and why-buy copy, channel copy.
- Cold-user path with a jobs-to-be-done explainer, one-question-at-a-time interview, and two named interview moments (one real customer plus raw specs; arguing with the four why-buys before stacking). Fast track for experienced or repeat users.
- Four-blade homepage as the default work product; press release, ad set, email sequence and sales one-pager derivations.
- Critique pass that blocks invented features, extended feature behaviour, facts placed in two cells, and copy that resolves an open question.
- Word export script (`scripts/export_docx.py`).
- Two fictional worked examples: a developer e-signature API and a consumer meal-planning app.
- Tested on six briefs with and without the skill; 89% versus 24% on the software and service set.
